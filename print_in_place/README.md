# APEX GT-01 打印说明

模型已经按原设计的 **60%** 输出。导入 `apex_racer_side_down.stl` 时保持 **100%**，**不要再缩小到 60%**。

侧放包围盒约 **119.7 × 32.4 × 56.4 mm**。保持已有朝向，轮轴沿打印 Z 方向、最低点为 Z=0。不要拆开排列车身、前轮组和后轮组，也不要填补轮组间隙。

根目录 `apex_racer.3mf` 为同一模型的通用 3MF，不含特定打印机切片参数。

## 当前造型

主车身重新绘制为连续平顺曲面，轮拱与机盖缓和衔接，前后四角以渐变弧线收拢，消除方正轮廓。最大车宽仍为 56.4 mm。

机盖和车尾向端部逐渐降低，底缘仅在最前、最后一小段平滑上收。端部中心截面厚度约为车头 5.9 mm、车尾 6.2 mm；前脸采用细长灯槽与单层宽进气口，轮拱仍完整覆盖胎面上方。

弧面车顶最高约 32.4 mm；侧窗从距热床约 0.5 mm 的外侧肩部起步，以约 45° 向内收拢，上部横向宽度约 43.4 mm。扩大前后风挡并增加后侧小窗，缩窄 A/C 柱。固定车门带 0.54 mm 宽门缝和凹槽把手；车窗与门缝凹深为横向 0.48 mm。曲面尾翼带后掠、收窄翼端、翘起后缘及渐变端板，最高约 29.4 mm。

车门不能开启，封闭车身内未建模座椅。预览中的深色窗面是显示配色，不是透明玻璃或多色打印材料。

四个轮拱均由加高、加宽的车壳覆盖胎面上方，轮胎与轮拱保留活动间隙。座舱后部以延长的溜背曲面逐渐接入后轮肩部和尾部平台。

## 前后附着

前轮前方和后轮后方保留永久贴床区域。输出文件车头平面贴床面积约 **83.9 mm²**，后轮后方车尾约 **69.0 mm²**，分别统计车身本体，不含轮胎和尾翼。

`bed_contact_preview.png` 中，绿色为车身首层，深灰色为轮组首层，黄色为加宽的前后保险杠。尾翼端板也在同一打印平面上。逐层确认前后保险杠和端板均从首层开始，必要时加外侧 brim。

## 切片起点

- 0.4 mm 喷嘴，0.16–0.20 mm 层高，3 圈壁，15–20% 填充。
- 按无支撑侧放设计：45° 侧窗、渐变尾翼端板、45° 支柱及轮毂，前脸开口也改为斜面收口。关闭支撑，逐层检查门缝与把手浅凹槽的短距离桥接。
- 轴孔活动间隙内不要生成支撑；检查象脚和残料是否连接轮组。
- 轴径 5.4 mm、孔径 6.6 mm，径向间隙 0.6 mm；轮胎与轮拱径向间隙 0.9 mm。这些尺寸已经包含整体缩放。

`validation_report.json` 记录实际输出尺寸、有效实体、闭合网格、前后贴床面积、双座参考包络及完整旋转检查。尚未实物试打，几何检查不等同于实物免支撑或转动手感验证。

已用 Bambu Studio 2.2.1.60 的 A1 mini / Generic PLA 配置，按以上参数关闭支撑完成 282 层试切片。报告记录了当前 STL 的校验值及切片结果。
